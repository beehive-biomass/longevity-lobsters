## 2. TikTok / Reels scripts

Three scripts that carry the funnel. Shoot vertical, 15–30 s, captions on
(everyone watches muted), Thai speech with EN text overlays (or A/B).

### R2 — "72 hours" (the protocol; saves-and-shares engine)

Screen-record style over Bee's actual morning, split into three chapters —
**The night of / The next morning / The 72 hours** (mirrors the gift's own
structure). Text-only voiceover energy, no face needed.

- Hook (0–3 s): `เต้นทั้งคืน ทำยังไงให้ร่างกลับมาเหมือนเดิมภายใน 72 ชม. // danced all night. here's the 72h comeback`
- Chapter cards in EN+TH; one rule per chapter (`ห้ามผสมอะไรกับอะไร // what NOT to mix`, `แสง · เคลื่อนไหว · hemp hearts // light · movement · hemp hearts`, `sleep debt · HRV · พักเมื่อไหร่ // when to rest`).
- End: `คู่มือเต็มอยู่ในนี้ เอาไปฟรี // the full protocol is a free gift → bio` 🦞

### R3 — "No account" (the differentiator; the share trigger)

- Hook (0–4 s): Bee deadpan to camera: `ทุกแอป: สมัครก่อน · อีเมลก่อน · จ่ายก่อน // every app: sign up, email us, pay first`
- 4–10 s: `แล้วพวกเขาเก็บข้อมูลเราไปด้วย // and then they keep your data`
- 10–18 s: screen shows the gift page promise line aloud: `ของขวัญนี้ ไม่ต้องสมัคร ไม่ต้องใช้อีเมล ไม่ต้องซื้ออะไรเลย // this one: no account, no email, nothing to buy` 🦞
- 18–25 s: `และข้อมูล เป็นของเรา คีย์เป็นของเรา // and the data stays yours. your keys.` → bio

### Story sequence (5 frames, runs the golden window Sunday morning)

1. Video boomerang: curtains opening, brutal light. Text: `09:47. ยังมีชีวิตอยู่ // still alive`
2. Poll: `คืนนี้นอนกี่โมง? // what time did you sleep?` [`ยังไม่นอนเลย 😵` / `ไม่กี่ชม. 😮‍💨`]
3. Water + electrolytes on nightstand. Text: `ชั่วโมงแรกเริ่มที่นี่ // hour one starts here`
4. The gift page, thumb hovering. Text: `เขาทำคู่มือนี้เป็นของขวัญฟรีจริง ๆ // someone made this a real free gift` 🦞
5. **Link sticker: `รับของขวัญ → take the gift`** (its own short link, `?src=ig-story-gift01`)
